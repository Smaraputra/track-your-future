# Contributing

Thank you for your interest in Track Your Future.

This project is **source-available, not open-source**. The code is published for
viewing, reference, and evaluation only. See [LICENSE](LICENSE) for the full terms.

## External contributions

External contributions are **not currently accepted**. Pull requests and feature
requests will not be merged, and issues may be closed without action. This may
change in the future; until then, please treat the repository as read-only.

You are welcome to read the code, study how it is built, and open a discussion if
you have questions.

## Security issues

Do not report security vulnerabilities through public issues. Please follow the
process described in [SECURITY.md](SECURITY.md).
